## Challenge: add water sounds

Select the **Stage**. Its Sounds tab already contains **Drip Drop**.

Add a quiet sound loop to play while you swim.

```blocks3
when green flag clicked
set volume to (25) %
forever
    play sound (Drip Drop v) until done
end
```

## Now run your code

Restart. Water sounds loop quietly while you play. You can still hear rescues and the hook sound.
